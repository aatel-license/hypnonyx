# Medium Article Structure Reference

## Full Template

```
---
[METADATA BLOCK]
---

# Title — Clear, Specific, Benefit-Oriented
## Subtitle — One evocative sentence that earns the click

---

[HOOK — 2–3 short paragraphs]
Problem or pain point → "I faced this too" → "Here's what I found"

---

## TL;DR  (only if >1500 words)
- Bullet 1: key takeaway
- Bullet 2: key takeaway
- Bullet 3: key takeaway

---

## [Section 1 — Context / Problem]
Why does this exist? What gap does it fill?
~200–350 words. One [IMAGE: diagram or screenshot] here.

---

## [Section 2 — Core Concept / Architecture]
The "what" before the "how".
Include a code snippet or diagram if applicable.

```lang
// illustrative snippet
```

---

## [Section 3 — Implementation / Deep Dive]
The "how". Step-by-step or subsection-by-subsection.

### Subsection A
### Subsection B
### Subsection C

---

## [Section 4 — Results / Demo / Benchmark]
Show don't tell. Numbers, screenshots, GIFs.
[IMAGE: demo screenshot or benchmark chart]

---

## [Section 5 — Lessons Learned / What's Next]
Honest reflection. What didn't work. What's on the roadmap.

---

## Conclusion
2–3 sentences max. Restate the core value delivered by the article.

---

## CTA
> ⭐ If this was useful, **star the repo on GitHub**: [link]
> 
> Follow me for more posts on [topic area].
> 
> **Question for you**: [engaging question to seed comments]
```

## Section Length Guidelines

| Section | Word count |
|---|---|
| Hook | 80–150 |
| TL;DR | 30–60 |
| Each H2 section | 150–400 |
| Code blocks (each) | ≤30 lines |
| Conclusion | 50–100 |
| CTA | 30–60 |

---

## Title Formulas That Work on Medium

- `How I Built X with Y (and What I Learned)`
- `X Is Not Y — Here's the Difference`
- `Why I Rewrote X in Y`
- `Building X: A Deep Dive Into Y`
- `Stop Using X for Y — Use Z Instead`
- `X in 5 Minutes: A Practical Guide`
- `The Hidden Complexity of X`
- `I Open-Sourced X — Here's the Architecture`

## Subtitle Formulas

- `A practical walkthrough of [concept] using [tool]`
- `What I discovered after [timeframe] of working on [project]`
- `From zero to [outcome] with [technology]`

---

## Engagement Patterns

**Opening hooks (rotate):**
1. *Question*: "Have you ever wondered why…?"
2. *Bold claim*: "Most developers are solving X the wrong way."
3. *Personal story*: "Three months ago, I was stuck on…"
4. *Surprising stat/fact*: "90% of LLM apps re-implement the same 200 lines of code."

**Transitions between sections:**
- "Now that we understand X, let's look at how Y works under the hood."
- "But there's a catch."
- "Here's where it gets interesting."

**Code block preamble:**
Always explain WHAT the code does BEFORE showing it, never after.

## Medium Import Tips (add at bottom of delivered file)

```
--- MEDIUM IMPORT NOTES ---
1. Use medium.com/p/import — paste the raw markdown URL or upload the .md file
2. After import: manually set the hero image (first [IMAGE] placeholder)
3. Check code blocks: Medium may strip syntax highlighting — verify after import
4. Tags: set them in the Medium editor, not from the metadata block
5. Canonical URL: set if cross-posting from your own blog
```
